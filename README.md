# 닌자 로얄 (NINJA ROYALE)

귀여운 도트 닌자 16명이 섬에 내려 싸우는 **8분 배틀로얄**.
롤식 조작(우클릭 이동·A 공격·QWER), 롤 챔피언을 본뜬 직업 스킬, 롤 아레나식 **증강 3택1**을 섞었습니다.

- 핵심 재미: **랜덤성 · 도박성 · 희열 · 중독성**
  - 상자를 열면 슬롯머신처럼 등급(실버·골드·프리즘)을 뽑고, 같은 등급 증강 3개 중 1개를 고름
  - 킬이 쌓이면 **현상금**이 붙고, 그 사람을 잡으면 좋은 상자(현상금 주머니)가 터짐
  - 목숨 1개. 죽으면 관전하거나 **바로 다음 판**
- 기획서: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) (맨 위 "닌자 로얄 개편" 장이 현재 기준)
- 전투 설계서: [docs/COMBAT_DESIGN.md](docs/COMBAT_DESIGN.md) — 직업 6종 스킬표

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start            # http://localhost:8080 (멀티플레이 서버 + 게임 페이지)
```

| 명령 | 하는 일 |
|---|---|
| `npm start` | 서버 실행. `PORT` 환경변수로 포트 변경 |
| `npm run dev` | 파일이 바뀌면 서버 자동 재시작 |
| `npm test` | 교전 시간·판 길이(약 8분) + 스킬·증강·상자·현상금·착지·자기장 + 서버 연결 테스트 |
| `npm run build:demo` | 서버 없이 열리는 단일 HTML 데모 → `dist/styx-demo.html` (그림 포함) |

## 한 판의 흐름

1. **착지** (10초): 섬 지도에서 내릴 곳을 클릭. 마을·유적은 큰 상자가 많지만 사람도 많음
2. **파밍**: 상자 열기(우클릭) → 등급 뽑기 → 증강 3택1 (`1` `2` `3` 키 또는 클릭, 싸우면서 골라도 됨). 정글 캠프를 다 잡으면 상자가 떨어짐
3. **자기장 5단계**: 0:50, 2:20, 3:50, 5:35, 7:05에 예고 → 줄어듦. 바깥은 초당 최대 체력 2~12% 피해
4. **마지막 1명** 우승. 죽으면 순위·보상을 보여 주고 관전 또는 다음 판

## 폴더 구조

```
shared/    게임 규칙. 서버와 브라우저(연습 모드)가 같은 코드를 실행
  sim.js        게임 루프: 착지, 상자→증강, 현상금, 자기장, 탈락·순위, 스냅샷
  augments.js   증강 30종 (실버 10 · 골드 11 · 프리즘 9)과 상자 등급 확률
  combat.js     스킬 실행, 피해, CC, 투사체, 장판, 증강 효과
  items.js      직업 6종 스킬 데이터 (밸런스 수정은 여기서)
  maps.js       섬 맵 (마을, 유적 6곳, 숲, 연못, 수풀, 정글 캠프, 상자)
  bot.js        봇 AI (판 흐름 조절: 생존 인원이 목표 곡선보다 적으면 봇끼리는 먼저 안 싸움)
  constants.js  판 시간, 자기장 단계, 체력, 보상
server/    WebSocket 서버: 공개 매칭, 비공개 방, 30틱 게임 루프
client/    도트 렌더러(pixel.js), 에셋 로더(assets.js), HUD, 메뉴, 이동 예측
  assets/       Ninja Adventure 도트 그림 (CC0) — 캐릭터·몬스터·타일·이펙트·UI
tests/     design.test.js, skills.test.js, server.test.js
tools/     데모 빌드
```

## 그림 출처

도트 그림은 **Ninja Adventure Asset Pack** (Pixel-Boy, AAA)을 썼습니다. 라이선스는 **CC0**(상업적 사용 가능, 출처 표시 의무 없음)이며, 고마움의 표시로 메뉴 하단에 이름을 적었습니다. 원본 라이선스: `client/assets/LICENSE-ninja-adventure.txt`

## 밸런스를 바꿀 때

1. 직업 수치는 `shared/items.js`, 증강은 `shared/augments.js`, 판 길이·자기장은 `shared/constants.js`
2. `npm test`로 교전 시간(약 5초)과 판 길이(약 8분)를 아직 지키는지 확인

## 아직 안 된 것

- 효과음 (일부러 뺌), 모바일 터치 조작, 팀전, 지역 서버
