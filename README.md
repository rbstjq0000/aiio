# 닌자 로얄 (NINJA ROYALE)

도트 닌자 16명이 지역 8곳(벚꽃·대나무·설산·묘지·단풍·소나무·협곡·이끼)의 큰 섬에서 싸우는 **10분 로그라이크 배틀로얄**.
모두 같은 닌자로 시작하고, **무기(상자)** 와 **증강(처치·에픽 몬스터)** 으로 판마다 다르게 강해집니다.

- 핵심 재미: **랜덤성 · 도박성 · 희열 · 중독성**
  - 상자를 열면 슬롯머신처럼 무기 등급(일반~전설)을 뽑고, 나에게만 뜨는 창에서 장착(F)·분해(G). 신화 무기는 중앙의 대텐구 보물에서만
  - 적을 잡으면 **그 적의 증강을 빼앗아** 3칸 중 하나에 넣음. 같은 계열을 모으면 세트 효과
  - 맵에 고정된 **에픽 몬스터 둥지**: 막타를 친 사람이 보물을 가져감 → 막타 뺏기·어부지리
  - 목숨 1개. 죽으면 관전하거나 **바로 다음 판**
- 기획서: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) (맨 위 0장이 현재 기준)
- 무기·증강 설계서: [docs/COMBAT_DESIGN.md](docs/COMBAT_DESIGN.md) — 무기 3종 스킬표, 등급 효과, 증강 24종, 상성 시뮬레이션

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start            # http://localhost:8080 (멀티플레이 서버 + 게임 페이지)
```

| 명령 | 하는 일 |
|---|---|
| `npm start` | 서버 실행. `PORT` 환경변수로 포트 변경 |
| `npm run dev` | 파일이 바뀌면 서버 자동 재시작 |
| `npm test` | 무기 상성(봇 결투 450판) · 판 길이(약 10분) + 스킬·무기·증강·에픽·티밍·맵 대칭 + 서버 연결 테스트 |
| `npm run build:demo` | 서버 없이 열리는 단일 HTML 데모 → `dist/styx-demo.html` (그림 포함) |

## 한 판의 흐름

1. **무기 고르기** (메뉴): 🗡 단도(리븐식 3단 베기) · ✴ 표창(베인식 구르기·벽꿍) · 📜 두루마리(아리식 구슬·매혹). 단도 > 두루마리 > 표창 > 단도 (스킬에서 오는 상성)
2. **시작 지점** (5초): 해안 은신처 16곳 중 하나에 무작위 배정. 맵이 8방향 대칭이라 어디든 조건이 같음
3. **파밍**: 은신처 → 지역 마을 → 에픽 둥지 → 가운데 도장. 몹 → 강화석(무기 등급 자동 상승, 전설까지). 캠프 상자는 몹을 다 잡아야 열림
4. **에픽 몬스터**: 작은 에픽 8곳은 1:30에 깨어남(잡히면 2:30 뒤 다시), 중앙 대텐구는 4:00에 한 번. 체력 30%가 되면 모두에게 알림
5. **자기장 5단계**: 1:30, 3:35, 5:30, 7:20, 8:55에 예고 → 줄어듦
6. **마지막 1명** 우승

## 폴더 구조

```
shared/    게임 규칙. 서버와 브라우저(연습 모드)가 같은 코드를 실행
  sim.js        게임 루프: 착지, 상자→무기, 강화석, 증강 제안·빼앗기, 에픽 둥지, 현상금, 자기장, 스냅샷
  items.js      무기 3종 × 6등급 스킬 데이터 (밸런스 수정은 여기서)
  augments.js   증강 24종 (6계열 × 4) · 세트 효과 · 실버/골드/프리즘
  combat.js     스킬 실행, 피해, CC, 투사체, 장판, 증강·세트 효과, 상성
  monsters.js   일반 몹과 에픽 몬스터 5종
  maps.js       대칭 섬 (반지름 6800: 지역 8곳, 은신처 16, 마을 8, 캠프 64, 에픽 둥지 8 + 대텐구)
  bot.js        봇 AI (판 흐름 조절: 생존 인원이 목표 곡선보다 적으면 봇끼리는 먼저 안 싸움)
  constants.js  판 시간, 자기장, 에픽 시간, 티밍 장치 수치, 보상
server/    WebSocket 서버: 공개 매칭, 비공개 방, 30틱 게임 루프
client/    도트 렌더러(pixel.js), 에셋 로더(assets.js), HUD, 메뉴, 이동 예측
  assets/       Ninja Adventure 도트 그림 (CC0) — 닌자 스킨·몬스터·보스·타일·이펙트·UI
tests/     design.test.js, skills.test.js, server.test.js
tools/     데모 빌드
```

## 그림 출처

도트 그림은 **Ninja Adventure Asset Pack** (Pixel-Boy, AAA)을 썼습니다. 라이선스는 **CC0**(상업적 사용 가능, 출처 표시 의무 없음)이며, 고마움의 표시로 메뉴 하단에 이름을 적었습니다. 원본 라이선스: `client/assets/LICENSE-ninja-adventure.txt`

## 밸런스를 바꿀 때

1. 무기 수치는 `shared/items.js`, 증강은 `shared/augments.js`, 판 길이·자기장·교전 피해 배율(PVP_DMG)은 `shared/constants.js`
2. `npm test`로 상성 경향(이기는 쪽 승률 47~75%)과 판 길이(약 8:20~11분)를 아직 지키는지 확인
