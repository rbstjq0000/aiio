# STYX.io 전투·승리 설계서 (확정 v1.1)

> 이 문서의 숫자가 기준이다. 구현은 이 숫자를 따르고, 시뮬레이션은 "목표를 달성했는지" 검증에만 쓴다.

## 0. 설계 목표 (검증 기준)

| 항목 | 목표 |
|---|---|
| 한 판 | 10분, 16인 개인전 |
| 1:1 교전 (같은 레벨·장비, 서로 다 맞힘) | **5초** |
| 1:1 교전 (잘 피할 때) | 10초 이상 |
| 1:2 교전 | 2~3초 → 빠질 타이밍 판단이 실력 |
| 최대 성장 격차 (15레벨 전설 vs 1레벨 일반) | **약 2배** (전투력 = 피해 × 체력, 즉 상대를 죽이는 데 걸리는 시간의 비) |
| 기절·속박 | 1회 최대 1초, 이후 1.5초 면역, 강한 CC는 모두 예고 표시 |

## 1. 승리 조건: 스틱스의 오브 3개

- 오브는 **2:00 / 4:00 / 6:00**에 하나씩 등장. 30초 전에 위치 예고, **오브 수호자(보스)**가 지킴
- 오브를 든 사람은 **위치가 모두에게 공개**됨, **자연 회복 없음**, 오브 1개당 **이동속도 -5%**
- 죽으면 들고 있던 오브를 **모두 떨어뜨림**

| 오브 | 효과 |
|---|---|
| 🔴 아레스의 오브 | 주는 피해 +15% |
| 🔵 포세이돈의 오브 | 받는 피해 -15% |
| 🟡 제우스의 오브 | 스킬 쿨타임 -20% |

- **승천 의식**: 3개를 모은 순간 시작. **15초를 버티면 승리**. 전원에게 경보와 위치 표시. 중간에 죽으면 오브가 떨어지고 의식은 취소됨
- **8:00**부터 스틱스 강이 맵을 덮기 시작. 10:00에 최소 크기
- **오브 보유 점수**: 오브를 들고 있는 동안 초당 (들고 있는 오브 개수)점. 점수는 죽어도 사라지지 않음
- **10:00 시간 종료**: 오브 보유 점수 1등이 승리. 동점이면 처치 수, 그다음 가한 피해량 순
  - 봇 테스트에서 "3개 승천"이 거의 나오지 않고 마지막 순간에 줍는 사람이 이기는 문제가 확인되어 추가함 (v1.1)

## 2. 죽음과 부활

- 부활 대기: **5초 + 경과 분당 0.7초** (최대 12초). 적이 없는 안전한 곳에서 부활. 부활 후 2초 무적
- 레벨은 유지
- 오브 전부와 **가장 좋은 장비 1개**(무기 제외)를 떨어뜨림. 빈칸은 기본 장비로 채움
- 처치 보상: 경험치 + 체력 25% 회복 + 떨어진 전리품

## 4. 전투 규칙

- 마나 없음, 쿨타임만 있음
- 기본 체력 **1,000**. 피해 숫자는 수십~수백 단위 (롤 감각)
- **궁극기 게이지**: 플레이어에게 준 피해 10당 1%, 초당 1% 자연 충전
- **CC**
  - 기절·속박·빙결: 최대 1초. 끝난 뒤 1.5초간 기절·속박 면역
  - 둔화: 최대 40%까지만 겹침
  - 강한 CC(기절·속박)는 바닥 예고, 날아오는 투사체, 또는 0.3초 이상의 준비 동작 중 하나가 반드시 보여야 함
- **무적**: 대시 신발 이동 중 0.16초
- **벽꿍**: 넉백으로 기둥에 박히면 50 피해 + 0.5초 기절
- 회복: 6초간 피해를 받지 않으면 초당 최대체력 2%. 오브를 들고 있으면 회복 없음

## 5. 성장

### 레벨 (몬스터 경험치)
- 1~15레벨. 레벨당 최대 체력·주는 피해 **+1.5%** (15레벨 = ×1.21)
- 레벨 경험치 곡선 목표: 2분 4레벨, 5분 8레벨, 9분 12~13레벨

### 장비 (상자·엘리트·보스·처치)
- 칸: **무기 / 갑옷 / 신발**
- 등급: 일반 ×1.00 / 고급 ×1.04 / 희귀 ×1.08 / 영웅 ×1.12 / 전설 ×1.17 (무기는 피해, 갑옷은 체력, 신발은 쿨타임과 속도에 적용)
- 최대 격차: 피해 1.21 × 1.17 ≈ 1.41배, 체력도 1.41배 → 처치 시간 차이 1.41 × 1.41 ≈ **2배**
  - 주의: 피해와 체력이 둘 다 오르면 격차는 곱해진다. 각각 2배로 두면 실제 격차는 4배가 됨
- 상자: 여는 데 **1초**, 맞으면 끊김. 맵에 30개, 열린 상자는 60초 뒤 다시 생김
- 다른 종류의 무기를 주우면 스킬 구성이 통째로 바뀜 (판 중에 무기 교체 가능)

## 9. 맵과 몬스터

- 원형 맵. 기둥·바위(엄폐와 벽꿍용), 상자 30개, 오브 제단 3곳
- 몬스터: 망령·해골 궁수·지옥 거한 (경험치용), **엘리트**(장비 드롭), **오브 수호자**(보스)
- 몬스터 피해는 체력 1,000 기준: 망령 30, 궁수 35, 거한 강타 80

## 10. 한 판 흐름

| 시간 | 일어나는 일 |
|---|---|
| 0:00 | 강하. 시작 무기(로비에서 선택) + 천 갑옷 + 질풍 장화, 모두 일반 등급 |
| 0:00~2:00 | 사냥, 상자 파밍 |
| 1:30 | 오브① 위치 예고 |
| 2:00 | 오브① 수호자 등장 → 첫 대규모 교전 |
| 4:00 / 6:00 | 오브②, 오브③ |
| 8:00 | 스틱스 강 축소 시작 |
| 10:00 | 종료. 오브 보유 점수 1등 승리 |
| 언제든 | 3개 모으면 승천 의식 15초 → 버티면 승리 |

## 11. 수익 연결

- 무기 스킨이 그 무기의 기본 공격과 스킬 이펙트 색을 바꿈 → 롤식 스킨 판매
- 성능에 영향을 주는 판매는 없음
