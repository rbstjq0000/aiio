# STYX.io 전투·승리 설계서 (확정 v2)

> 이 문서의 숫자가 기준이다. 구현은 이 숫자를 따르고, 시뮬레이션은 "목표를 달성했는지" 검증에만 쓴다.
>
> v2 변경: 롤식 조작(우클릭 이동 + 좌클릭 공격 + QWER + DF), 스킬 각인 등급과 R 세트 효과, 정글 캠프, 벽·방 구조 맵, 부활 8~30초, 사망 시 스킬 강등, 오브 보유 효과 강화

## 0. 설계 목표 (검증 기준)

| 항목 | 목표 |
|---|---|
| 한 판 | 10분, 16인 개인전 |
| 1:1 교전 (같은 레벨·등급, 서로 다 맞힘) | 근접 **5초**, 원거리·CC 5.5~6초 |
| 1:1 교전 (잘 피할 때) | 10초 이상 |
| 1:2 교전 | 2~3초 → 빠질 타이밍 판단이 실력 |
| 최대 성장 격차 (15레벨·전설 vs 1레벨·일반) | **약 2배** (전투력 = 피해 × 체력, 즉 상대를 죽이는 데 걸리는 시간의 비) |
| 기절·속박 | 1회 최대 1초, 이후 1.5초 면역, 강한 CC는 모두 예고 표시 |
| 레벨 곡선 | 2분 4레벨, 5분 8레벨, 9분 12레벨 |

## 1. 승리 조건: 스틱스의 오브 3개

- 오브는 **2:00 / 4:00 / 6:00**에 하나씩 등장. 30초 전에 위치 예고, **오브 수호자(보스)**가 지킴
- 오브를 든 사람의 페널티는 **위치가 모두에게 공개**되는 것 하나뿐
- 대신 보유 효과가 큼 (오브 1개당 최대 체력 +8%, 이동 속도 +4% 공통)

| 오브 | 효과 |
|---|---|
| 🔴 아레스의 오브 | 주는 피해 +25% |
| 🔵 포세이돈의 오브 | 받는 피해 -25% |
| 🟡 제우스의 오브 | 스킬 쿨타임 -30%, 궁극기 게이지 충전 2배 |

- 죽으면 들고 있던 오브를 **모두 떨어뜨림**
- **오브 보유 점수**: 들고 있는 동안 초당 (들고 있는 오브 개수)점. 죽어도 점수는 남음
- **승천 의식**: 3개를 모은 순간 시작. **15초를 버티면 즉시 승리**. 전원에게 경보
- **8:00**부터 스틱스 강이 맵 중앙(성소)으로 좁혀짐. 10:00에 최소 크기
- **10:00 시간 종료**: 오브 보유 점수 1등 승리. 동점이면 처치 수, 그다음 가한 피해량

## 2. 죽음과 부활

- 부활 대기 (롤식): **8초 + 경과 분당 1.2초 + 레벨당 1초**, 최대 30초. 적이 없는 곳에서 부활, 2초 무적
- 죽어 있는 동안 **오브 보유자를 관전** (←/→로 전환)
- 사망 패널티
  - 오브 전부 떨어뜨림
  - **가장 높은 등급의 스킬 하나가 한 단계 강등** (R 세트 효과가 깨질 수 있음)
  - 레벨은 유지
- 처치 보상: 경험치 + 체력 25% 회복

## 3. 조작 (롤 방식)

| 키 | 동작 |
|---|---|
| 우클릭 | 그 지점으로 이동 (누르고 있으면 커서를 계속 따라감). 상자·장비 위에서 누르면 걸어가서 열기/줍기 |
| 좌클릭 | 마우스 방향 기본 공격 (누르고 있으면 연속) |
| Q · W · E | 무기 스킬 (마우스 방향으로 즉시 시전). E는 대부분 이동기 |
| R | 궁극기 (게이지 100%) |
| D · F | 보조 주문 (대기실에서 5개 중 2개 선택) |
| S | 제자리 멈춤 |

## 4. 전투 규칙

- 마나 없음, 쿨타임만 있음. 기본 체력 **1,000**
- **궁극기 게이지**: 플레이어에게 준 피해 10당 1% (몬스터는 0.3%), 초당 1% 자연 충전
- **CC**: 기절·속박·빙결 최대 1초 → 끝난 뒤 1.5초 면역. 둔화는 최대 40%까지만 겹침
- 강한 CC는 바닥 예고, 날아오는 투사체, 0.3초 이상의 준비 동작 중 하나가 반드시 보임
- **벽꿍**: 넉백으로 벽·기둥에 박히면 50 피해 + 0.5초 기절
- **벽**: 이동과 투사체를 막음. 점멸은 벽을 넘을 수 있음
- 회복: 6초간 피해를 받지 않으면 초당 최대체력 2%

## 5. 성장: 레벨 + 장비 두 갈래

### 레벨 (정글 캠프)
- 1~15레벨. 레벨당 최대 체력·주는 피해 **+1.5%** (15레벨 = ×1.21)
- 경험치는 정글 캠프 몬스터에서. 롤 정글처럼 동선을 짜서 돌아야 함

### 장비
- **스킬 각인**: 내 직업의 Q·W·E 중 하나의 등급을 올림 (고급 ~ 전설). 무기 자체는 판 중에 바뀌지 않음
  - 나오는 곳: 상자, 일반 몬스터(낮은 확률), 엘리트(확정), 오브 수호자(확정, 높은 등급)
  - **R 세트 효과**: Q·W·E가 모두 희귀 이상이면 R 등급 = 셋 중 가장 낮은 등급
- **갑옷·신발**: 능력치 장비 (체력, 이동, 쿨감, 피해 감소). 상자에서 나옴
- 상자: 우클릭하면 걸어가서 1초 동안 열기, 맞으면 끊김. 열린 상자는 60초 뒤 다시 생김
- 최대 격차: 피해 1.21 × 1.17 ≈ 1.41배, 체력도 1.41배 → 처치 시간 차이 약 **2배**
  - 주의: 피해와 체력이 둘 다 오르면 격차는 곱해짐

## 7. 맵 (shared/maps.js)

- 맵은 데이터로 정의: 벽(선분), 기둥, 오브 제단, 정글 캠프, 상자, 시작 위치, 최종 안전지대. **새 맵은 MAPS에 항목을 추가**하면 됨
- 첫 맵 **명계 폐허**
  - 중앙 성소(문 4개) → 오브 제단 3곳이 있는 중간 지대(방사형 벽으로 3구역, 문 6개) → 방 6개와 엄폐벽이 있는 바깥 지대
  - 캠프: 망령 무리(40초 리젠), 해골 궁수대(50초), 지옥 거한(60초), 망령 기사(엘리트, 1분 뒤 첫 등장, 90초)
- 캠프 몬스터는 자리를 벗어나 끌려가면 돌아감
- 봇은 격자 A* 길찾기로 벽을 돌아서 이동

## 8. 한 판 흐름

| 시간 | 일어나는 일 |
|---|---|
| 0:00 | 바깥 지대에서 시작. 고른 직업의 기본 스킬(일반 등급) + 천 갑옷 + 질풍 장화 |
| 0:00~2:00 | 정글 캠프·상자로 레벨과 스킬 등급 올리기 |
| 1:00 | 엘리트 캠프 첫 등장 (스킬 각인 확정) |
| 1:30 → 2:00 | 오브① 예고 → 수호자 등장 → 첫 대규모 교전 |
| 4:00 / 6:00 | 오브②, 오브③ |
| 8:00 | 스틱스 강이 중앙으로 좁혀짐 |
| 10:00 | 종료. 오브 보유 점수 1등 승리 |
| 언제든 | 3개 모으면 승천 의식 15초 → 버티면 승리 |

## 9. 수익 연결

- 무기 스킨이 그 무기의 기본 공격과 스킬 이펙트 색을 바꿈 → 롤식 스킨 판매
- 성능에 영향을 주는 판매는 없음
