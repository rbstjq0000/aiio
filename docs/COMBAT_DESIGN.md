## 0. 설계 목표 (검증 기준, `npm test`)

| 항목 | 목표 | 현재 (봇 결투 300판씩, 희귀 등급) |

| CC | 기절·속박 1회 최대 1초, 이후 1.5초 면역 | 단도는 40% 짧게 받음 |
| 판 길이 | 약 10분 | 9:29~9:51, 생존 2분 12~14명 / 4분 9~12 / 6분 6~8 / 8분 3~4 |

상성은 따로 붙는 보너스 없이 **무기마다 다른 스킬·패시브**에서 나온다.
- 🗡 단도 > 📜 두루마리: 패시브 **그림자 탈출**(기절·속박 -40%)로 두루마리의 묶기를 버티고 붙음
- ✴ 표창 > 🗡 단도: 패시브 **바람 발걸음**(기본 공격 적중 시 이동 +8%)과 둔화·공중제비로 거리를 벌림
- 📜 두루마리 > ✴ 표창: 사거리가 더 길고(800 vs 700), 패시브 **잿불**(화상 걸린 적의 원거리 기본 공격 속도 -15%)로 표창의 평타 싸움을 꺾음

## 1. 무기 등급

등급이 오를 때마다 피해·체력이 조금 오르고, 정해진 스킬 하나가 강화된다. 상자에서는 일반~전설, 신화는 대텐구 보물에서만. 상자 무기는 연 사람에게만 창으로 뜨고(장착 또는 분해), 쓰러진 닌자의 무기만 바닥에 떨어진다. 일반 몹이 주는 강화석이 모이면 들고 있는 무기 등급이 자동으로 오른다(전설까지).

| 등급 | 피해·체력 배율 | 열리는 효과 |
|---|---|---|
| 일반 | ×1 | - |
| 고급 | ×1.04 | 우클릭 강화 |
| 희귀 | ×1.08 | Q 강화 |
| 영웅 | ×1.12 | W 강화 |
| 전설 | ×1.16 | E 강화 |
| 신화 | ×1.2 | R 강화 |

강화석: 일반→고급 8개 · 고급→희귀 14개 · 희귀→영웅 22개 · 영웅→전설 32개

## 3. 판 흐름 장치

| 장치 | 수치 |
|---|---|
| 상자 무기 | 연 사람에게만 창이 뜸: F 장착(들던 무기는 강화석으로) / G 분해(강화석). 같은 무기는 더 높은 등급만 장착 |
| 에픽 몬스터 | 작은 에픽 8곳 1:30에 깨어남, 잡히면 2:30 뒤 다시. 대텐구(중앙) 4:00에 한 번. 체력 30%에 전체 알림 |
| 에픽 보물 | 막타 친 사람 앞에 떨어짐. 여는 데 3초, 다른 플레이어에게 맞으면 끊김. 골드 이상 증강 (대텐구는 전설·신화 무기 + 프리즘 위주 증강) |
| 처치 보상 | 상대 증강 중에서 고름(빼앗기) + 무작위 증강. 건너뛰면 강화석 3개 |
| 어시스트 | 6초 안에 때린 사람: 강화석 3개 + 체력 회복 |
| 다수 피격 | 2초 안에 3명 이상에게 맞으면 받는 피해 -15% |
| 전투 이탈 | 3초 동안 안 때리고 안 맞으면 이동 +20% |
| 강자 표시 | 무기 등급 색 테두리, 영웅 이상은 오라, 이름 위에 증강 계열 아이콘 |
