# 닌자 로얄 무기·증강 설계서 (v5)

> 숫자는 `shared/items.js`, `shared/augments.js`, `shared/constants.js`에서 그대로 옮겼다. 표를 고칠 때는 코드부터 고친다.

## 0. 설계 목표 (검증 기준, `npm test`)

무기 셋은 롤에서 1:1 손싸움으로 유명한 챔피언의 스킬 구성을 빌려 왔다 (이름·그림은 닌자식).

| 무기 | 빌려 온 스킬 구성 | 핵심 |
|---|---|---|
| 🗡 단도 | 리븐 | Q 3단 돌진 베기(3번째 기절) · W 기절 · E 돌진+보호막 · R 강화 → 다시 누르면 처형 검기 · 패시브 칼날 기운 |
| ✴ 표창 | 베인 | Q 구르기+강화 평타 · W(자동) 3연속 적중 % 피해 · E 단죄(벽꿍 기절) · R 사냥의 시간(구르면 은신) |
| 📜 두루마리 | 아리 | Q 왕복 구슬 · W 유도 여우불 · E 매혹(걸어옴) · R 3번 질주+유도탄 |

| 항목 | 목표 | 현재 (봇 결투 300판씩) |
|---|---|---|
| 무기 상성 | **스킬 자체에서만** 나오는 경향 (무기별 수치 보정 없음) | 표창 > 단도 64~70%, 단도 > 두루마리 50~65%, 두루마리 > 표창 64~75% |
| 교전 | 롤처럼 짧고 굵게 | 1:1 약 8~10초. 플레이어끼리 피해 ×2 (모든 무기 같음), 기본 공격 밀치기 없음 |
| 등급 격차 | 일반 → 신화 피해×체력 1.44배 | 등급마다 스킬 하나씩 강화 |
| CC | 기절·속박 1회 최대 1초, 이후 1.5초 면역 (매혹은 최대 1.5초) | |
| 판 길이 | 약 10분 | 9:49~9:51 |

상성이 생기는 이유 (스킬이 하는 일)
- 🗡 단도 > 📜 두루마리: 3단 베기 + 돌진으로 650 넘게 파고들어 기절을 연달아 넣음. 몸이 약한 술사는 매혹이 빗나가면 버티지 못함
- ✴ 표창 > 🗡 단도: 단죄로 다가온 단도를 밀어내고 벽에 박으면 기절, 구르기로 거리를 유지하며 3연속 % 피해
- 📜 두루마리 > ✴ 표창: 매혹으로 사수를 끌어오고 유도 여우불·왕복 구슬이 구르기로 피하기 어려움

## 1. 무기 등급

등급이 오를 때마다 피해·체력이 조금 오르고, 정해진 스킬 하나가 강화된다. 상자에서는 일반~전설, 신화는 대텐구 보물에서만. 상자 무기는 연 사람에게만 창으로 뜨고(장착 또는 분해), 쓰러진 닌자의 무기만 바닥에 떨어진다. 일반 몹이 주는 강화석이 모이면 들고 있는 무기 등급이 자동으로 오른다(전설까지).

| 등급 | 피해·체력 배율 | 열리는 효과 |
|---|---|---|
| 일반 | ×1 | - |
| 고급 | ×1.04 | 우클릭 강화 |
| 희귀 | ×1.08 | Q 강화 |
| 영웅 | ×1.12 | W 강화 |
| 전설 | ×1.16 | E 강화 |
| 신화 | ×1.2 | R 강화 |

강화석: 일반→고급 8개 · 고급→희귀 14개 · 희귀→영웅 22개 · 영웅→전설 32개

## 3. 판 흐름 장치

| 장치 | 수치 |
|---|---|
| 상자 무기 | 연 사람에게만 창이 뜸: F 장착(들던 무기는 강화석으로) / G 분해(강화석). 같은 무기는 더 높은 등급만 장착 |
| 에픽 몬스터 | 작은 에픽 8곳 1:30에 깨어남, 잡히면 2:30 뒤 다시. 대텐구(중앙) 4:00에 한 번. 체력 30%에 전체 알림 |
| 에픽 보물 | 막타 친 사람 앞에 떨어짐. 여는 데 3초, 다른 플레이어에게 맞으면 끊김. 골드 이상 증강 (대텐구는 전설·신화 무기 + 프리즘 위주 증강) |
| 처치 보상 | 상대 증강 중에서 고름(빼앗기) + 무작위 증강. 건너뛰면 강화석 3개 |
| 어시스트 | 6초 안에 때린 사람: 강화석 3개 + 체력 회복 |
| 다수 피격 | 2초 안에 3명 이상에게 맞으면 받는 피해 -15% |
| 전투 이탈 | 3초 동안 안 때리고 안 맞으면 이동 +20% |
| 강자 표시 | 무기 등급 색 테두리, 영웅 이상은 오라, 이름 위에 증강 계열 아이콘 |
