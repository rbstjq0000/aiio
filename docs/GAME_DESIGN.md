## 2. 전투·승리 설계

**→ 숫자까지 확정된 내용은 [COMBAT_DESIGN.md](COMBAT_DESIGN.md) 참고.** 요약:

- 10분, 16인 개인전. 빈자리는 봇
- 2·4·6분에 오브 3개 등장 (보스가 지킴). 들고 있으면 위치 공개 + 강한 버프 + 초당 점수
- 3개 모아 15초 버티면 즉시 승리(승천), 아니면 10분 뒤 오브 점수 1등 승리
- 성장 두 갈래: 정글 캠프 → 레벨, 스킬 각인 → Q·W·E 등급 (셋 다 희귀 이상이면 R도 상승)
- 죽으면 8~30초 뒤 부활. 오브 전부 떨어뜨리고 가장 높은 스킬 하나가 한 단계 강등
- 1:1 교전 약 7초, 최대 성장 격차 약 2배, CC 최대 1초 + 1.5초 면역

## 8. 수익 모델 — Pay-to-Win 절대 금지, 치장품만

### 재화 (OpenFront.io와 같은 이중 재화)
- **오볼** (무료): 판 끝날 때마다 획득 (기본 8 + 킬당 6 + 순위 보너스, 1등 50)
- **영혼석** (유료): 현금으로만 충전. 현금으로 아이템을 직접 팔지 않고 재화만 판매

### 판매 상품 — “남들 눈에 보이는 것”이 잘 팔림
| 분류 | 예시 | 비고 |
|---|---|---|
| 스킨 | 잿불 영혼, 심연의 그림자, 서리 왕관, 황금 영웅, 별에서 온 아이 | 몸체 색·장식·애니메이션 |
| 대시 잔상 | 불꽃, 전류, 벚꽃잎, 별가루, 무지개, 공허 | 대시할 때마다 노출 → 과시욕 |
| 스킬 이펙트 | 지옥불, 비전, 신성, 맹독, 프리즘 | 베기 색 (로드맵: 무기별 스킨이 스킬 이펙트까지 바꿈, 롤식) |
| 처치 효과 | 천벌, 꽃의 장례, 블랙홀, 축포 | 상대가 죽을 때 모두에게 보임 |
| 칭호 | 망령 사냥꾼(업적), 스틱스의 지배자(업적), 신들의 총애(유료) | 이름 아래 표시 |

### 가격 예시
- 영혼석: ₩1,200=100개 / ₩5,900=550개 / ₩11,900=1,150개 / ₩29,000=3,000개
- **올림포스 패스 (구독)** 월 ₩4,900: 광고 제거, 매달 영혼석 300, 오볼 +50%, 전용 스킨
- **시즌 배틀패스** (로드맵) ₩9,900: 무료/유료 트랙

### 광고
- 메뉴 배너 (io 게임 전문 광고망: AdinPlay 등)
- 판 사이 전면 광고 (3판에 1번, 첫 3판은 없음)
- **보상형 광고**: “광고 보고 오볼 2배” → 가장 반응 좋은 형태
- 구독자/구매자는 광고 제거

### 유통
1. **CrazyGames / Poki** 등록 → 무료 트래픽 + 광고 수익 쉐어 (OpenFront.io도 CrazyGames SDK 연동)
2. 자체 도메인 (styx.io 같은) + 광고망
3. 반응 좋으면 Steam 데스크톱 버전 (OpenFront.io도 Steam 연동)

결제: 국내 토스페이먼츠 / 해외 Stripe 또는 Xsolla (게임 특화, 세금 처리)

## 9. 중독성 장치
- 죽어도 판에 남음 (부활), 대신 스킬 강등이라는 확실한 손해
- 매 판 스킬 등급 성장이 달라짐 (상자·몬스터·엘리트에서 나오는 각인)
- 레벨업, 전설 장비 획득, 오브 획득, 킬 스트릭 아나운스(“더블 킬!”, “학살!”) 같은 도파민 순간
- 일일 퀘스트 3개, 연속 접속 보상(7일차 영혼석), 계정 레벨, 업적 칭호
- 결과 화면의 아쉬움 연출 (“1등까지 2명 남았었습니다”)
- 로드맵: 시즌 랭크, 듀오/스쿼드 모드, 클랜

| **지금 (MVP)** | 이미지 파일 0개. 캐릭터·몬스터·이펙트를 전부 코드로 그림 (네온 발광 + 파티클) | 로딩이 빠름(io 게임은 첫 접속 3초가 생명), 저작권 걱정 없음, 스킨 추가가 코드 몇 줄 |
| 알파 | 핵심 스프라이트만 교체: 캐릭터 스킨, 몬스터 4종, 제단 | 매출이 나는 치장품부터 퀄리티 투자 |
| 출시 | 2D 일러스트 외주 (크몽, ArtStation) + 스프라이트 시트, 렌더러를 WebGL(PixiJS)로 전환 | 객체가 많아져도 60fps 유지 |

> 하데스 아트를 따라 그리거나 가져다 쓰면 안 됨. 그리스 신화 자체는 누구나 쓸 수 있지만, 하데스의 그림·글·음악은 저작권 보호 대상.

## 11. 핑(지연) 문제 해결 구조

| 문제 | 해결 | 상태 |
|---|---|---|
| 해킹·조작 | **서버 권한(authoritative)**: 피해·처치·레벨업 판정은 서버만 함. 클라이언트는 입력만 보냄 | ✅ 구현 |
| 내 캐릭터가 늦게 움직임 | **클라이언트 예측**: 이동·대시는 내 화면에서 즉시 움직이고, 서버 결과가 오면 입력 번호로 맞춰 보정(reconciliation). 오차는 부드럽게 흡수 | ✅ 구현 |
| 남들이 순간이동처럼 보임 | **보간(interpolation)**: 다른 유닛은 0.1초 전 상태 둘 사이를 부드럽게 그림 | ✅ 구현 |
| 공격 반응이 늦음 | 클릭 즉시 내 화면에서 휘두르는 모션·효과음 재생, 피해 판정만 서버 | ✅ 구현 |
| 데이터량 | 내 주변만 전송, 숫자 압축 배열 | ✅ 구현 / 바이너리 프로토콜·델타 압축은 로드맵 |
| 물리적 거리 | **지역 서버**: 서울·도쿄·미국·유럽. 접속 시 핑 측정 후 가까운 지역 자동 선택 | 🔜 배포 단계 |
| 원거리 판정 억울함 | 넉넉한 판정 + 텔레그래프(예고) 위주 설계로 100ms까지 체감 최소화. 필요하면 서버 되감기(lag compensation) | 🔜 로드맵 |
| 핑 표시 | 화면에 ms 표시, 200ms 이상 경고 | ✅ 구현 |

서버 사양: 30틱. Node.js 한 프로세스가 16인 판 여러 개를 동시에 돌림. 판이 늘면 프로세스와 지역을 늘림.

## 12. 기술 구조

```
shared/   게임 규칙 (서버와 브라우저가 같은 코드 사용)
  sim.js        게임 루프: 맵, 오브, 부활, 상자/장비, 스틱스 강, 스냅샷
  combat.js     스킬 실행, 피해, CC, 투사체, 장판
  items.js      무기(기본 공격+QWER)·스킬 등급·갑옷·신발·오브 데이터
  maps.js       맵 데이터 (벽, 캠프, 상자, 제단) — 새 맵은 여기 추가
  nav.js        봇 길찾기 (A*)
  monsters.js   몬스터 데이터와 AI
  bot.js        봇 AI
  cosmetics.js  치장품 카탈로그
server/   Node.js + WebSocket: 공개 로비, 비공개 방, 30틱 게임 루프
client/   메뉴, 상점, 렌더러, 이펙트, 사운드, HUD, 입력 예측
```

- 연습 모드(봇전)는 **브라우저 안에서 같은 게임 규칙 코드를 돌림** → 서버 없이도 플레이 가능
- 계정·결제·랭킹 DB는 알파 단계에서 추가 (Supabase 또는 Postgres)
